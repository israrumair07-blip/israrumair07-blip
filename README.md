### Blood Donor Management System

A full-stack platform for blood donor registration, city/blood-group filtering and administrative management.

- Modal-based async CRUD with the Fetch API: real-time table updates without page reloads
- Donor eligibility automated with Carbon (90-day cooldown period)
- Laravel notifications via Gmail SMTP send instant email alerts to admins for approval
- Responsive Crimson Red UI with strict server-side validation and regex-based phone sanitization

`PHP` `Laravel` `MySQL` `Bootstrap 5` `JavaScript`
